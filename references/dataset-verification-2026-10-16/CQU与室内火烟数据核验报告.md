# CQU与室内火烟数据核验报告

核验日期：2026-10-16，北京时间。环境：工作目录内Miniconda `sci-env`。本轮只做数据下载、标签/图像完整性核验、视觉质检和统计规划，没有加载模型权重、训练、推理、跨数据集查重、改标或删图。

## 1. 结论

**两套数据的文件级核验已经完成，但目前均不能认定补足了纯火保护和低误报确认所需的可靠真值。**

- **CQU：** 按标签有3,999张仅火和4,192张名义无火图，数量有潜力；但抽查直接发现另一类别漏标，空标签图中也有明显火烟。不能把标签中未出现某类解释为该类确实不存在。暂不纳入确认性纯火/低FAR评价。
- **室内库：** 有5,000张图和完整配对标签，但类别名称仅为`0/1`；抽查支持`0≈fire、1≈smoke`，发布包与原项目均未给出明确语义映射。没有空标签背景；存在仅类别0图中的烟雾样区域未标，以及类别1涵盖疑似雾化器气溶胶的例子。需先明确类定义与完整性，暂不纳入确认性纯火/低FAR评价。
- 不剔除问题图片、不重新标注、不挑出“看起来干净”的子集来制造达标。保留完整原包和核验记录，原D-Fire/FASDD规模、SCI二区目标及全部效果门槛不变。

## 4. 室内库实际计数

包内`data.yaml`只有`names: ['0','1']`；[原Roboflow项目](https://universe.roboflow.com/object-detection-7qn6l/indoor-fire-smoke)也只显示两个数字类别。下表先按ID统计，避免凭习惯写死语义。

| 发布划分 | 图像/标签对 | 仅ID0 | 仅ID1 | 同时有0/1 | 空标签 | ID0框 | ID1框 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 3,500 | 1,520 | 1,665 | 315 | 0 | 2,504 | 2,342 |
| valid | 750 | 319 | 353 | 78 | 0 | 547 | 496 |
| test | 750 | 326 | 358 | 66 | 0 | 541 | 505 |
| 合计 | **5,000** | **2,165** | **2,376** | **459** | **0** | **3,592** | **3,343** |

抽查支持ID0通常对应火焰、ID1通常对应烟/气溶胶。因此条件性地看，名义纯火为2,165、仅烟为2,376、共存459、背景0；**这不是已正式确认的语义映射或完整四态真值**。

文件级结果：5,000图对应5,000标签，缺标签0、孤立标签0、图像解码失败0、非法类别/列数/非有限/非正面积框0。严格边界检查发现85图的86框轻微超出图像边界，最大仅0.5像素；属于与边界取整相容的小偏差，不能据此说85张图损坏。原值保留，不静默裁框或剔除图像。

主要尺寸：640×640共1,971，416×416共1,068，720×1280共520，1280×720共420，另有多种尺寸。小火焰数在正式语义映射确认前记为未计算，不能把未知记成0。

该包来自Roboflow v1 Original，原平台列出5,000图和3500/750/750划分，说明该版本没有额外预处理/增强；不将8,500图增强v2混用。不能据此保证原始汇集素材没有视频近邻或历史处理。

## 5. 标注完整性：格式完整与语义完整分开

按固定SHA-256排序，每个声明组抽取最多12个不同文件名前缀的样本；CQU空标签组仅2张，全部检查。共查看CQU38张、室内36张。这是确定性的分层质量抽查，**不能由此估计全库错误比例，也不能证明剩余图片无误**。

### 5.1 CQU已发现足以影响结论的例子

| 证据 | 原标签 | 视觉观察与影响 |
| --- | --- | --- |
| [仅火样本2](cqu-example-fire_only-2.jpg) | 只有一个class0框 | 火焰旁有大范围黑烟。该图不能作为已确认“无烟火焰”保护样本 |
| [仅烟样本7](cqu-example-smoke_only-7.jpg) | 只有三个class1框 | 树林中有明显火焰。将其作为无火图，会把正确检火误计为FP |
| [空标签样本1](cqu-example-background-1.jpg) | 空文件 | 图像可见火焰和烟。空标签不能作可靠负真值 |
| [空标签样本2](cqu-example-background-2.jpg) | 空文件 | 有明显灰色气溶胶/烟雾样区域，缺少语义协议，不能确认两类皆无 |

这并非只有格式问题。即使每个标签文件都存在、所有框都合法，“没有某类标签”仍不能直接推出“该类不存在”。CQU的3,999名义纯火、4,192名义无火不应直接进入严格保护/误报分母。

### 5.2 室内库的语义问题

观察样本通常支持0为火、1为烟，但发布类名没有明确说明。部分仅ID0样本可见烟雾/烟霾样区域而没有ID1；[ID1样本11](indoor-example-label1_only-11.jpg)标注的是疑似雾化器/扩香器上方气溶胶。需要作者协议确定“smoke”是否包含非燃烧水雾、如何处理弥散烟，以及是否完整标注另一类。

没有空标签背景不代表不存在漏标，也不能提供灯光、反射、云雾等纯背景上的低FAR验证。只用仅烟图测fire-FAR，最多支持该条件场景的结果，不能替代完整无火背景分布。

所有观察以[视觉质检记录](visual-review.json)和固定样本清单留档，不作为新人工真值，不改原标签。联系作者、获取修订发布或更换合规公开资源是后续选择；本轮没有向任何人发送消息。

## 6. 相关性与统计能力

### 6.1 样本数不能直接当独立事件数

只在各数据集内部统计Roboflow哈希后缀之前的文件名前缀，没有比较两个数据集的图像或文件，也没有执行跨库查重。

- CQU：11,021文件对应7,265种前缀，2,214个前缀有多文件，879个前缀跨发布划分；名义仅火覆盖2,421种前缀。
- 室内：5,000文件对应3,913种前缀，643个前缀有多文件，375个前缀跨划分；仅ID0覆盖1,881种前缀，仅ID1覆盖1,738种前缀。

前缀只是相关性线索，可能重名，也漏掉不同前缀的同场景，不能当事件ID或去重结果。图像抽查亦可见视频/固定场景画面。全库作为未参与训练的补充评价时，库内部原train/test交叠不自动构成本项目训练泄漏，但其有效统计量仍受相关性影响。

### 6.2 纯火保护：数量有潜力，真值尚未满足

以下是假设标签完整、样本独立的规划示例，不是模型结果，也不是已证明的样本能力。对图像级配对召回差，设真实差为0、非劣效界1pp、单侧α=0.05、功效80%，以q表示两方法结论不一致的概率，正态规划近似为：

`n ≈ (z_0.95 + z_0.80)^2 × q / 0.01²`。

| 假设q | 约需独立适格样本 |
| ---: | ---: |
| 1% | 619 |
| 2% | 1,237 |
| 5% | 3,092 |
| 10% | 6,183 |

CQU名义3,999图在某些理想条件下可能够，室内名义2,165图在较低不一致率时可能够；但二者的纯火真值未确认，相关性和多重检验还会提高需求。不能宣布已补足。

仅官方test的395/326张，在“零新增漏检、全部独立且适格”这一特殊条件下，单侧95%新增图像漏检风险上界约0.756%/0.915%。这种最好情形不等同于净召回非劣效保证；只要有错误、相关性或不同分母就会变化。框级召回还需目标数和组内相关性，不能直接套图像n。

### 6.3 低误报：不能把数千张名义负图当已足够

用原目标的例子：FAR从1.0%降至0.7%，即相对降低30%、绝对差0.3pp。在正确独立配对的图像上，用单侧精确McNemar检验α=0.05，计算达到80%功效的条件样本量：

| 两模型报警状态不一致率q | 约需独立负图 |
| ---: | ---: |
| 0.3%，最有利的只纠正不新增错误情形 | 2,239 |
| 0.7% | 5,178 |
| 1.7% | 12,242 |

这是对已知假设参数的精确检验功效规划，不包含多重比较、阈值估计或事件相关性。不是当前模型有这些误报率。

CQU全量名义负图4,192，1%时约42次报警；室内暂按ID1解释的负图2,376，约24次。中间q=0.7%的规划功效分别约71%和46%，均低于80%。只用官方test的415/358负图，1%时约4次报警，难以可靠确认30%相对改善。

更关键的是，CQU名义负图有可见火焰漏标；室内缺少可靠类定义和背景覆盖。统计公式无法修复错误真值。两库不能直接合并得到6,568“独立无火图”，也不能与FASDD相加后声称跨库重合已控制。

完整可复现计算：[统计规划JSON](statistical-capacity.json)、[统计脚本](../../code/dataset-verification-2026-10-16/statistical_capacity.py)。

## 7. 对独立方案的决定

1. 保留原D-Fire、FASDD_UAV、Pyro角色和全部主门槛，不替换主数据、不降低纯火1pp保护或FAR相对改善30%要求。
2. CQU与室内库暂定为**已完成文件审计、未通过确认性语义准入**；原包和全部标签保留，未加入训练、校准或正式测试。
3. CQU需要完整双类标注协议/修订版和来源说明；室内需要0/1明确映射、烟/气溶胶定义、完整标注规则及足量可靠背景。仅作者一句映射解释不能自动解决视觉发现的漏标。
4. 在不新增人工标注的现有约束下，优先寻找作者已发布的完整修订或其他合规公开原标注库；不能通过本轮抽查挑样本、改标签或模型筛图来宣称补足。
5. 数据补足关卡仍未通过。可以继续文献、方法设计及数据调查，不进入依赖“纯火保护和低FAR已可确认”的完整模型实验。
