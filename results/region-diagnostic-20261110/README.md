## 核心判断

当前证据更支持把任务兼容的区域语义作为有限强度的辅助信息继续研究，而不支持直接把教师分数当整张图片的质量权重。现有六选项接口不适合直接用于加权。原生评分有部分额外信息，但尚未证明区域辅助训练能提高检测器；本阶段没有启动这类训练。

原因：六选项分数明显偏烟、顺序敏感；原生四态接口改善候选区分和原GT支持，但其对真实火/烟仍有低支持案例，缺乏独立标注错误真值。直接按低分压低整图权重，可能损失可靠难例。候选级正向信号更贴近区域辅助任务；训练GT仍应主导。
